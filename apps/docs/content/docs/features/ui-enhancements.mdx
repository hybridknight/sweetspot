---
title: YouTube Music enhancements
description: Small playback and interface improvements in the embedded music view.
---

Sweet Spot automatically dismisses YouTube Music toast messages after a short delay and applies performance improvements to the embedded music view.

User-configurable options live in [Playback & shortcuts](/docs/features/playback), [Shared links](/docs/features/shared-links), [Lyrics](/docs/features/lyrics), and [Themes](/docs/features/themes).

For implementation details, see the renderer plugins in the project source. The music view uses context isolation and a narrow bridge to the desktop app.
