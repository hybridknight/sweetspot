title: Browser userscript
description: Open ssytm:// from music.youtube.com / youtube.com via Tampermonkey
---

The **Sweet Spot Open Links** userscript soft-opens actionable YouTube Music / YouTube / youtu.be pages in the desktop app via `ssytm://` when you load or SPA-navigate to them.

It does **not** intercept link clicks — browsing in the tab stays normal.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Build the script from the monorepo:

```bash
pnpm userscript:build
```

3. Open `packages/userscript/dist/sweetspot-userscript.user.js` in the browser and confirm install.

Matched hosts: `music.youtube.com`, `youtube.com`, `m.youtube.com`, `youtu.be`.

Sweet Spot must be installed (or the `ssytm://` protocol registered) so the OS hands the URL to the app.

## Behavior

| Event | Action |
| --- | --- |
| Page load / SPA navigate | If that **host setting** is on and the URL is actionable, soft-open `ssytm://…` (tab stays) |
| Link click | Unchanged — browser follows https as usual |

Actionable paths: watch (`?v=`), playlist (`?list=`), channel (`/channel/UC…`), `@handle`, `/shorts/…`, `/embed/…`, and youtu.be `/{videoId}`. Home, search, and browse are skipped.

Transform is the same address-bar trick as [shared links](/docs/features/shared-links): `https://` → `ssytm://` on convertible hosts.

## Tampermonkey menu

Open the Tampermonkey / Violentmonkey menu on a matched page:

| Command | Default | Effect |
| --- | --- | --- |
| **Sweet Spot: music.youtube.com — ON/OFF** | ON | Auto-open on load/navigate for Music |
| **Sweet Spot: youtube.com — ON/OFF** | OFF | Auto-open for youtube.com / www |
| **Sweet Spot: m.youtube.com — ON/OFF** | OFF | Auto-open for mobile YouTube |
| **Sweet Spot: youtu.be — ON/OFF** | OFF | Auto-open for short links |
| **Sweet Spot: Open this page now** | — | Open current URL as `ssytm://` (ignores host toggles) |

Settings persist via `GM_setValue`.

## Develop

```bash
pnpm userscript:dev
```
